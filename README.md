# The Systems Journey — A Security+ Learning Project

A free, openly usable learning program for CompTIA Security+ (V7),
built as a journey through nine systems (of systems) that I found interesting rather than a list of exam topics.

## What This Is

This project teaches CompTIA Security+ by investigating, building, breaking,
defending, and explaining real-world systems — with every lesson tied to an
explicit, atomically numbered Security+ objective.

The project is organized as:

- **Mission Atlas Register** — the master architecture: program philosophy,
  mission register, the cross-mission ownership and crossover model, and the
  mapping of every Security+ atomic requirement to its owning mission.
- **Mission Passports** — one design document per mission: scenario,
  system architecture, core questions, planned Security+ coverage, labs,
  artifacts, failure/attack scenarios, and completion gates.
- **Sub-Requirements Matrix** — the authoritative universe of Security+ V7
  atomic requirements (`1.1-A` through `5.6-E`).
- **Setup documents** — scaffolding and setup materials placed in each
  mission folder ahead of execution.
- **Learning artifacts** — the tangible outputs each mission produces
  (diagrams, registers, policies, captures, playbooks, reports).

The governing principle:

> **Security+ is the destination. The Mission Atlas is the vehicle.**

## Status: Work In Progress

This project is **not complete** and is actively being developed.

**Completed:** Mission 01 — up through Segment 1.2, including all
setup documents leading to that point.

**Scaffolding:** Missions 02–09 contain their setup
documents and templates only. These folders are deliberate scaffolding —
the architecture and coverage plans for missions that have not yet been
executed. Their presence is the roadmap. 

## Roadmap

The program runs through nine missions, in order:

| #   | Mission                                         | Focus                                                     | Status                                     |
| --- | ----------------------------------------------- | --------------------------------------------------------- | ------------------------------------------ |
| 01  | How Does My Phone Reach Google?                 | Networking, secure communications, cryptography, identity | In progress — Phase 1, through Segment 1.2 |
| 02  | How Does Starlink Get a Packet to the Internet? | Satellite networking, routing, distributed infrastructure | Designed                                   |
| 03  | Build the Secure Innovation Lab                 | Enterprise security architecture & controls               | Scaffolded                                 |
| 04  | The Network Is Compromised                      | Threats, detection & incident response                    | Scaffolded                                 |
| 05  | Build a Secure AI Capability                    | Application, data & AI security                           | Scaffolded                                 |
| 06  | Build the Drone ISR System                      | Mobile, wireless & operational security                   | Scaffolded                                 |
| 07  | Move the System to the Cloud                    | Cloud architecture & IAM                                  | Scaffolded                                 |
| 08  | The System Nobody Understands                   | Governance, risk & compliance                             | Scaffolded                                 |
| 09  | Everything Is Failing                           | Resilience, continuity & capstone integration             | Scaffolded                                 |

Each mission is updated as it is executed; this repository is a live
work-in-progress and grows as missions complete.
